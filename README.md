# 练习日 · 黑白训练面板

[打开交互 Demo](https://lila253.github.io/fitness-checkin-demo/)

健身打卡小程序的黑白风格设计演示，包含今日、计划、统计、我的四页。

支持开始／结束训练、直接打卡、组数计数、本周与下周训练计划编辑，以及在“我的”页面直接修改选填昵称和头像。

这是设计 Demo，日期和初始数据为固定示例；尚未接入微信登录、后端或数据库。演示状态仅保存在当前浏览器，上传头像只在当前页面会话内保留。

发布页的图片、样式、图标脚本已内嵌，不依赖外部 CDN。

本站使用 GitHub Pages。地址没有预设到期时间，持续可用取决于仓库和 Pages 服务保持启用。
